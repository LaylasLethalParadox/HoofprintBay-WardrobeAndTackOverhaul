Wardrobe and tack overhaul 1.0.0 for Horses of Hoofprint Bay, the first release.

Save an outfit for your rider and a set of tack for each horse for training, trail rides, lessons, Caprilli, jumping and cross country. The wardrobe and Edit Tack get a tab for each of them and a Save button, and a ride uses the set saved for it. Anything you don't save uses the game's own outfit or tack.

Halters with lead rope now come in red, yellow, green and purple for 40 each, sold in the equipment store's ear bonnet list. Every horse starts with the blue one, and you pick a horse's halter on the Halter tab in Edit Tack.

Requires BepInEx 6 bleeding edge build 793 (IL2CPP, Windows x64). Mod Manager is optional and shows the on/off setting in the Mods menu. Made for game version 1.0.5. Extract the zip into the game folder.
